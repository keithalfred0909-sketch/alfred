# Abogado personal IA

Asistente jurídico personal para Derecho español (estatal, catalán, europeo y municipal):
análisis de casos, investigación en fuentes oficiales, revisión de documentos y borradores.

No sustituye la revisión de un abogado colegiado.

Estado: Fase 0 (plan y estructura). Ver [`PROJECT_PLAN.md`](PROJECT_PLAN.md).
